# OAuth 首次 WS 配置

WS 模式和 HTTP 流式 WS 加速统一在首次配置的顶层控件设置，账号初始设置中不再重复显示。旧模板或旧客户端的 `account_settings.openai_ws_mode`、`account_settings.openai_ws_sse_acceleration` 在读取和保存时迁入顶层字段并清除内层值；两处都有值时保留旧内层的明确选择，包括 `off` 和 `false`，避免被历史顶层默认值覆盖。保存后只保留一处配置来源，原有 `shared`、`dedicated` 模式也保留在统一入口中。

在「自动配置 → OAuth 账户首次配置」选择 OpenAI，可设置「WS 模式」并勾选「HTTP 流式 WS 加速」。WS 模式默认选择上下文池，流式加速默认关闭；WS 模式也可选择关闭、透传或 HTTP 桥接。

启用首次配置并保存后，仅对后续新建的 OpenAI OAuth 账号应用这两项模板值，覆盖导入数据中的对应设置。其他平台、API Key 和观察者导入不继承这些设置；已有账号、重新授权和手动编辑不重新应用模板。两项与 429 后更换 2FA、429 后关闭调度分别保存，可同时使用。

模式选择沿用账号编辑中的规则：关闭会禁用账号 WS，其他模式仍受全局 WS 开关约束；需要启用 `gateway.openai_ws.mode_router_v2_enabled` 才按所选模式路由，未启用时使用上下文池。HTTP 流式 WS 加速建议搭配上下文池并关闭自动透传，已绑定的传输插件优先；此模板不修改全局开关、账号透传设置或传输插件绑定。WS 关闭时，即使勾选流式加速，也不会启用该传输路径。

这两项通过可选字段 `openai_ws_mode` 和 `openai_ws_sse_acceleration` 保存在现有自动配置 setting 中，不增加数据库迁移。旧模板缺失字段时保留原初始化行为；在页面保存后，才将显示的上下文池和加速勾选状态写入模板。API 客户端省略字段时保留当前模板值；显式传入 `off` 或 `false` 可覆盖导入的启用状态。
