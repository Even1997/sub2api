# Sub2API 2.20.0

- 发布前安全扫描发现 GO-2026-6859，编译与发布工具链统一升级到 Go 1.27.4，修复 net/http 的 MaxBytesReader 并发崩溃问题。

- 全量纳入当前应用与重登 worker 的累计改动，包括此前云猫微信二维码、回调处理、退款、内容审核及 OAuth 配置修复。已人工补款的订单不重复处理。
- 选择性集成 ranxi v2.20.5 的 14 项功能修复：OAuth 429 周额度阈值、API Key 自动兜底、停调候选和跨页选择、可信 OAuth 401 清理、重登调度恢复、原生降智控制、托管 BPS 调度和缓存创建计费、WS/SSE 无终态、页面上下文及图片授权。
- 保留本地首次配置、成本倍率、BPS 和首响应策略。Serverless 超时补丁依赖已删除模块，本次未引入；本发布不代表与上游 v2.20.5 整仓一致。
- 修复分组绑定与模型限制跨数据库连接自锁，相关状态和调度通知在同一事务提交。
- 新增数据库迁移 344、345、346。发布前备份数据库；回退二进制不会自动撤销持久规则处置。
- 验证：前后端构建、230 项 PostgreSQL/Redis 回归、相关定向回归、支付回归及桌面/手机界面检查通过。完整默认测试套件仍有旧接口和 Windows 兼容问题，未宣称全套通过。详细证据见 ranxi-v2.20.5-integration-2026-11-11.md。

40 服务器发布入口：deploy/40-bluegreen-v2200.sh。新端口 18280/18281，切换前保留旧实例、Caddy 配置、数据库备份及 worker 恢复档案；云猫沿用 40 直连。
