# Sub2API v2.25.0 (Even)

本版在 Even v2.24.0 基础上，选择性集成 Ranxi v2.24.3 至 v2.25.3 的兼容改动。

- 改进 OpenAI、Claude 和 Grok 的请求转换、流式事件与工具调用兼容性。明确的上下文超限按请求错误处理，避免误标账号质量或触发无效切号。
- 频道监控 V3 支持为一个组件选择多个模型，公开状态页同步展示。新增迁移 399，已有单模型配置可继续读取。
- 运维分组支持阈值和轮询配置，限流列表按未来重置时间筛选。修正部分千问推理参数和 DeepSeek Key 用量窗口。
- 验签通过后的支付履约使用独立超时，避免客户端断连打断处理和清理。

数据库迁移和双实例切换已在 Even 生产环境验证。各项集成范围、暂缓内容和测试说明见[集成记录](https://github.com/Even1997/sub2api/blob/v2.25.0/docs/ranxi-v2.25-integration.md)。
