# Sub2API v2.24.0 (Even)

本版包含 Even PR #19 和 #20，选择性移植上游 v2.23.1 至 v2.24.2 的改动，保留 Even 的账号调度、切号预算和会话隔离。

- 账号批量编辑支持配置自动使用重置卡，可分别调整 5h 和 7d 窗口。默认不修改现有账号；此设置只适用于 OpenAI OAuth 主账号。
- Qwen / Wan 视频支持异步生成、查询和下载，默认关闭。提交时锁定每秒价格，完成后按上游计费秒数结算；重复查询和下载不会重复扣费。
- Claude 账号可选请求最低扣费，默认关闭。开启后也适用于普通低金额 Token 请求，不改变原始 Token 或采购成本。账号页可按实测使用率估算 5h 和 7d 窗口成本。
- 临时 OAuth 429 的同号重试只回到原发送账号；明确配额耗尽时仍按 Even 原有策略切号。Grok 搜索按上游成功调用数计费，图片编辑最多支持五张原图。
- 修复 Gemini 工具结果分轮和流式事件边界，改进同用户批量结算与恢复、账号用量统计及模型价格币种展示。

本版没有新增数据库迁移。定向回归已覆盖主要迁移路径；完整 CI 仍有失败项。未移植的上游功能、测试范围和已知问题见[逐项集成记录](https://github.com/Even1997/sub2api/blob/v2.24.0/docs/ranxi-v2.24-integration.md)。
